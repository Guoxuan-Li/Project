# Q&A

## What is this blog about?

It can be anything -- writing, travel, books, recipes, or a mix of all of them. The template gives you the structure; you bring the content.

## Can I customize the colors?

Yes. All colors are defined as design tokens in `_sass/_variables.scss`. Each page uses one of five accent colors (sakura, sora, matcha, yuzu, sumire), and you can change them in one place.

## How do I add a new page?

Most pages are listing pages that reuse the same template. You just create a markdown notebook file and configure the page front matter. See the README for details.
