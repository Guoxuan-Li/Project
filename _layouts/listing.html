Page front matter (set in the page file): section : page section key (bookshelf / recipes / etc.) accent : accent color key eyebrow : small label above title card_mode : "row" (vertical row expansion) or "modal" (global overlay) card_prefix : CSS class prefix for cards (e.g. "book", "recipe") collapsed_lines: how many lines to show when collapsed (default 6) search_scopes : space-separated scope keys search_labels : pipe-separated scope labels search_placeholder search_unit : count unit label collection_key: which collection to read the notebook from (the notebook.md file inside that collection) The content from /notebook.md is rendered to HTML inside a hidden
